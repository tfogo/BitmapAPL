# APL385 Unicode

Original font artwork by Adrian Smith, placed in the public domain.

Source: the APL385 font distributed with Dyalog 20.0.53963 for macOS.
Dyalog documents the public-domain dedication and links to the author's site:
https://www.dyalog.com/apl-font-keyboard.htm
https://apl385.com/fonts/

Bundled locally so APL glyphs render without installing a system font or contacting a font service.
