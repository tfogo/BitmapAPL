These lessons use a JavaScript model, checked against outputs from the real Dyalog library. The page does not execute APL. A moving window explains dependencies; it does not imply that APL processes pixels in this animation order.

Numbers stay signed and unrounded during calculation. Grayscale views clip to 0–255; signed views use blue for positive values and orange for negative values, with signs printed in each cell. Sobel magnitude is scaled for display. All coordinates below use ⎕IO←1.

Try the color-plane sample to see how BlurPlane⍤2 applies independently to each plane of a rank-three image. Its RGB teaching planes are separate from the BMP adapter’s BGRX byte order.
