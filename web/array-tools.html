THE SAME IDEAS, MORE PLACES TO USE THEM

Color, detail,
and array notation

A few more ways to put arrays to work on a picture.

The main walkthrough began with grayscale so each pixel needed just one number. Color adds another axis. Other operations change positions, compare values, or combine two images. The array ideas still apply.

Three planes make a color

For this example, store red, green, and blue as three planes of the same size. The array’s shape is 3 height width. Indexing can select one plane.

⎕IO ← 0
red ← image[0;;]
green ← image[1;;]
blue ← image[2;;]

The semicolons separate axes. Leaving an axis empty selects all its positions. Change the selected plane below. The grayscale view shows that channel’s numeric intensity.

softColor ← (4 1 'clamp') ImageOps.BlurImage image

Inside this function, Rank applies the plane blur to each two-dimensional cell. The leading channel axis keeps the planes separate.

The BMP adapter stores B, G, R, and a fourth preserved byte. It filters only the three color planes. The teaching image here uses R, G, B order. The fourth BMP byte is not treated as transparency.

Change positions with one symbol

⌽ reverses the last axis. In a matrix, that flips each row from left to right. The numbers keep their values.

flipped ← ⌽picture

A comparison draws a boundary

A threshold turns a grayscale image into a Boolean mask. Each value becomes 1 if it is at least the threshold, or 0 otherwise.

mask ← picture≥128

The comparison works on every value. A value exactly equal to the threshold is included. This is a simple starting point for the binary shapes used in the later articles.

Keep the sign of a change

A gradient can be negative. Reversing a brightness transition reverses its response. Taking a magnitude is useful for edge strength, but loses that direction information.

g ← 'clamp' ImageOps.Sobel picture
g.gx ⋄ g.gy
strength ← ((g.gx*2)+g.gy*2)*0.5

Subtract a blur to find detail

Blur removes quick changes. Subtract the blurred image from the original and those changes remain as a signed detail layer. Add some of that layer back to make edges stronger.

soft ← (2 1 'clamp') ImageOps.BlurPlane picture
detail ← picture-soft
sharp ← picture+1.5×detail

This is unsharp masking. An amount of zero returns the original. Too much creates bright and dark halos and exaggerates noise.

sharp ← (2 1 1.5 'clamp') ImageOps.Unsharp picture

Negative values and values above 255 remain in the array. The display and BMP writer clip them to the visible range. Clipping inside the calculation would lose information.

Another way to write a weighted sum

We started the first article with multiplication followed by addition. APL can combine those two functions in an inner product.

weights ← 0.25 0.5 0.25
neighbors ← 20 60 220
+/weights×neighbors     ⍝ 90
weights+.×neighbors     ⍝ 90

The dot connects the two functions: multiply matching values, then add their results. With a matrix of windows, the same notation computes several outputs at once.

windows ← 2 3⍴20 60 220 60 220 60
windows+.×weights       ⍝ 90 140

The library keeps a matrix version of the row filter as a teaching reference. Stencil avoids building that full window matrix. Both are checked against the same results; their speed depends on the array and window sizes.
